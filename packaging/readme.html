安装内容

  • /Library/Audio/Plug-Ins/HAL/Wannengya.driver — 四个双向虚拟设备
  • /Library/Audio/Plug-Ins/VST3/wannengya Capture.vst3 — 采集
  • /Library/Audio/Plug-Ins/VST3/wannengya Return.vst3 — 回传
  • /Applications/wannengya Agent.app — 后台服务

装完之后

  1. 系统设置 → 声音，应能看到 wannengya 1/2 … 7/8。
  2. 如果看不到，打开终端执行： sh scripts/doctor.sh（安装目录下），它会指出是哪一步没生效。
  3. 在 Studio One 里插上 万能鸭录音机架 Capture，第一次选择 App 时会请求 「屏幕与系统音频录制」权限（仅 macOS 14.2+；更早的系统上应用下拉框是灰的， 请改用虚拟通道）。

卸载

删除上面四个路径，然后重启音频服务即可。或运行安装目录下的 sudo sh scripts/uninstall.sh。
